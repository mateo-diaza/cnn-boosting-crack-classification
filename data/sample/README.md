# Atribución y licencia de la muestra

Las imágenes de esta carpeta proceden del conjunto **Concrete Crack Images for Classification**, versión 2, creado por **Çağlar Fırat Özgenel** y publicado en Mendeley Data en 2019:

- Fuente: <https://data.mendeley.com/datasets/5y9wdsg2zt/2>
- DOI: <https://doi.org/10.17632/5y9wdsg2zt.2>
- Licencia del conjunto de datos: [Creative Commons Atribución 4.0 Internacional (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/)

Esta carpeta contiene una selección de 10 imágenes de cada clase (`Negative` y `Positive`) del conjunto original. Las imágenes se han copiado sin modificar y se conservan sus nombres de archivo. La selección de una muestra reducida es la modificación realizada.

La licencia MIT del código de este repositorio no se aplica a estas imágenes. Al reutilizarlas, conserva esta atribución y cumple las condiciones de CC BY 4.0.
